# Pizza Delivery Bot 🍕🛵

Telegram-бот та веб-панель для замовлення та управління доставкою піци.

## Можливості

- **Інтерактивне меню**: перегляд страв за категоріями (піца, напої, десерти, соуси), фотографії та актуальні ціни.
- **Кошик замовлень**: додавання страв, зміна кількості та оформлення замовлення.
- **Оформлення доставки**: вибір адреси, способу оплати та коментарів до замовлення.
- **Веб-додаток (WebApp)**: зручний вибір страв через вбудований Telegram WebApp.
- **Панель адміністратора**: сповіщення про нові замовлення, зміна статусів («готується», «в дорозі», «доставлено»).

## Стек технологій

- Python 3.11+
- aiogram 3.x
- FastAPI / Flask
- SQLite
- HTML5, CSS3, JavaScript

## Розгортання

Сервіс налаштований для роботи на сервері під керуванням systemd (`pizza-delivery-bot.service` та `pizza-webapp.service`) з автоматичним деплоєм через GitHub Actions.
